# Healthcare Management System

A healthcare management system frontend built using Next.js.

## Features

- Dashboard with healthcare statistics
- Role-based navigation for administrators, doctors, and patients
- Login page with client-side form validation
- Patient registration page
- Responsive, professional healthcare-themed interface

## Tech Stack

- Next.js
- React
- JavaScript
- CSS
- Lucide React

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Current Status

The frontend UI is under development. Authentication and database integration are pending.

## Project Structure

- `app/` — Pages and global styles
- `app/login/` — Login page
- `app/register/` — Patient registration page
- `components/` — Shared layout and navigation components
